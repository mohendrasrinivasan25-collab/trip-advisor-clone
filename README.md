# TripAdvisor Clone

A front-end TripAdvisor clone website created using HTML5 and CSS3. 
This project is designed to recreate the look and feel of a travel and 
exploration platform while practicing webpage structure, layout design, 
styling, and responsive UI development.

## 🌐 Live Demo

🔗 [View the Live Website](https://mohendrasrinivasan25-collab.github.io/trip-advisor-clone/)

## 📌 About the Project

The TripAdvisor Clone is a static front-end web project inspired by the 
TripAdvisor travel platform. The main purpose of this project is to practice 
and demonstrate fundamental front-end development skills using HTML and CSS.

The website focuses on creating a clean travel-oriented interface with 
different sections for exploring destinations, travel experiences, and 
related content. The layout, spacing, typography, images, navigation, and 
other visual elements are designed to provide a user-friendly browsing 
experience.

This project does not use JavaScript, frameworks, or backend technologies. 
It was developed using basic HTML and CSS to strengthen the fundamentals 
of web design and front-end development.

## ✨ Features

- Clean and structured navigation bar
- Travel-focused homepage design
- Destination and travel content sections
- Image-based travel presentation
- Styled buttons and navigation elements
- Organized content sections
- Responsive layout using CSS
- Clean spacing, alignment, and typography
- Simple and user-friendly interface
